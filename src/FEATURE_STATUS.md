# 前端功能状态

## 已实现

- 响应式前台布局、深色模式、Cookie 统计授权提示、全局错误边界和 404。
- 文章列表、详情、归档、搜索页面；Markdown/GFM 渲染与代码复制。
- SEO 基础标题与描述更新；隐私政策入口。
- 读者注册/邮箱验证码登录页面及管理员后台的概览、文章、编辑器、媒体库、站点设置界面。
- 代码按路由懒加载（见 `main.tsx`）。

## 后端或第三方依赖导致的占位

| 功能 | 阻塞条件 | 当前行为 |
| --- | --- | --- |
| 读者注册、登录、找回/注销 | `/auth/*`、JWT/Cookie、验证码限流和用户接口 | 表单可提交，接口失败时明确提示，不会伪造登录 |
| 极验 | Site Key、服务端二次校验 | 登录页提示待接入 |
| COS/CDN 正文图片 | 服务端 COS 凭证与 CDN HTTPS | 文章编辑页已接入预签名直传和上传完成校验；媒体库仍未实现 |
| 百度统计/PV/UV | 生产站点 ID、同意后动态加载、analytics API | 不显示虚构指标 |
| 分类、标签、搜索、归档数据 | 对应公开 API | 页面框架可用；当前仅用已有文章列表做客户端搜索 |
| 文章管理/发布/自动保存 | 管理员鉴权、POST/PATCH/DELETE API | 编辑器不提交数据 |
| RSS、sitemap、Open Graph 图片 | 后端/构建期页面数据 | 尚未生成静态产物 |
| 部署状态/飞书记录 | 云效回调与安全的后端查询 API | 后台展示占位提示 |
